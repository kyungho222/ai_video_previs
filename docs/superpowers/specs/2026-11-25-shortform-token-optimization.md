## 목적과 측정

새로 받은 원본을 기준으로 최적화한다. 앞서 작성한 통합 기획 구현을 복원하거나 대규모 필수 응답 스키마를 다시 도입하지 않는다.

- 목표: 시나리오부터 최종 영상 검증까지 전체 실제 total_tokens 합계를 원본의 1/3 이하로 줄인다. 이미지 입력·이미지 생성 모델이 보고한 토큰, 실패·보정·전송 재시도 사용량을 포함한다.
- 최종 영상 프롬프트는 8,000자 내외를 목표로 한다. 필수 정보는 삭제하지 않으며 공급사 한도 안에서 초과를 허용한다.
- 문자 수 절감은 토큰 목표 달성의 증거가 아니다. input/output/cached/total_tokens와 실제 호출 수를 모델별·단계별로 비교한다. 캐시 토큰은 total_tokens에서 임의 차감하지 않는다.
- 초 단위 영상 과금, 요청당 이미지 과금 등은 토큰과 별도로 기록한다. 사용량이 누락된 요청을 0으로 계산해 목표를 달성했다고 판단하지 않는다.
- 카메라·동선 정확도, 에셋 정체성, 자연스러운 동작을 유지한다. 실제 생성 결과로 검증하기 전에는 1/3 달성을 선언하지 않는다.

## 인터뷰 확정 사항

1. 전체 과정의 토큰을 1/3로 절감한다.
2. 중복 호출·프롬프트를 통합하고 불필요 호출을 제거한 뒤 역할별로 모듈화한다.
3. 시작 이미지 한 장을 가급적 한 번만 생성하고 첫 프레임으로 고정한다. 종료 이미지는 생성하지 않는다.
4. 후속 구도·동선·행동·마무리는 텍스트로 전달한다. 동작의 세부 관절 연출은 영상모델에 맡긴다.
5. 저장된 프리비즈 설계·카메라·동선·행동 데이터는 재사용한다. 외부 업로드 MP4만 필요한 분석을 수행한다.
6. 에셋만 교체하면 카메라·동선·행동은 유지하고 매핑·시작 이미지만 갱신한다.
7. 데이터 문제는 Python이 우선 보정한다. 의미가 불명확해 복원할 수 없을 때만 해당 단계의 AI 보정을 최대 1회 요청한다.
8. 최종 영상 AI 검증은 1회 실행한다. Python으로 복구할 수 없는 시각적 오류는 영상모델 재생성을 최대 1회 허용한다.
9. 최종 프롬프트 8,000자는 목표값이며 필수 정보의 초과를 허용한다.

## 최적화 흐름

```text
사용자 입력
 → 안전검사(인젝션·수위 판정 통합 + 별도 moderation)
 → 시나리오 작성
 → 프리비즈 장면 설계
 → Python 검증·보정·컴파일 → Blender 렌더
 → 저장된 카메라·동선·행동 재사용
    [외부 MP4만: 장면 변화·중요 행동 표본 분석]
 → 에셋 정체성·대응 관계 분석(분리된 호출을 한 번으로)
 → 시작 이미지 한 장 생성 → 필요한 정체성·구도 확인
 → Python 최종 프롬프트 조립·중복 제거·길이 검사
 → 기존 모델 어댑터로 영상 생성
 → 최종 영상 AI 검증 1회
 → 데이터·컨테이너·음원 문제는 Python 보정
 → 심각한 신체·외형·필수 행동 오류만 최대 1회 재생성
 → 결과와 검증·보정 기록 반환
```

최종 영상 검증 1회 제한에 맞춰 재생성본에는 추가 AI 검증을 하지 않는 안이다. 파일 재생·길이·해상도·스트림 등 로컬 검사는 수행한다. 재생성이 품질 개선을 보장한다고 표시하지 않는다. 이 세부 동작은 구현 전 설계 검토에서 명시적으로 확인한다.

## AI와 Python 역할 경계

| AI 판단 | Python 마무리 |
| --- | --- |
| 사용자 의도·행동·대사·연출 해석 | ID·타임라인·참조 무결성·필드 형식 검사 |
| 새 에셋의 정체성과 대상 대응 | 명시적인 ID 별칭 정규화, 원본 설계 재사용 |
| 외부 MP4에서 불확실한 동작·카메라 해석 | 내부 프리비즈 설계에서 카메라·좌표·동선 직접 추출 |
| 이미지·완성 영상의 시각적 문제 판정 | 프롬프트 조립·중복 제거·수치·시간 변환·공급사 요청 구성 |
| 복원 불가능한 의미 오류에 대한 1회 수정 | 음원 합성·허용된 영상 포맷 변환·파일 무결성·사용량 기록 |

Python이 추정해 채우면 안 되는 값: 불명확한 캐릭터 정체성, 실제로 모르는 bbox 단위, 원본에 없는 행동·대사·언어, 알 수 없는 위치·가림 관계. 경고를 없애려고 임의 기본값을 넣지 않는다.

## 모듈 경계

새 대형 통합 기획 호출 대신 기존 모듈에 소유권을 정하고, 다음 공용 모듈만 필요에 맞게 추가한다. 파일명은 구현 시 기존 구조와 중복되는지 확인한다.

- `prompt_policy.py`: 공통 영상 규칙 단일 정의. 캐릭터 유지·동작·카메라·오디오 지시를 한 번씩만 포함.
- `prompt_assembler.py`: 사용자 요청·확정 타임라인·캐릭터 계약·에셋 대응을 최종 프롬프트로 조립. 자체 AI 호출 없음.
- `scene_reference.py`: 내부 설계와 업로드 MP4를 구분하고 저장된 카메라·동선·행동 참조를 제공.
- `asset_mapping.py`: 캐릭터 시트 해석·대상 매핑을 한 호출로 처리. 카메라나 행동을 다시 설계하지 않음.
- `recovery_policy.py`: Python 복원 가능/AI 의미 보정 필요/진행 불가 구분, 보정·재생성 횟수 관리.
- `analysis_cache.py`: 콘텐츠 해시·정책 버전·사용자 범위·선택 모델을 기준으로 분석 재사용. 다른 사용자 자료와 혼용 금지.
- 기존 `ai_usage.py`·`stage_usage.py`: 실제 호출 단위 기록과 단계별 비교. 병렬 호출의 사용량 소유권 보존.

기존 모델 어댑터·로그인·DB 사용량 등록·History 저장 인터페이스는 유지한다. 운영·로컬 저장 방식을 이번 작업에서 재구성하지 않는다.

## 호출·캐시·보정 규칙

- 안전검사는 인젝션·수위 판정을 한 번으로 합치되 차단 규칙을 약화하지 않는다. moderation은 별도 수행한다. 생성 작업이 시작되기 전에 완료되어야 한다.
- 같은 canonical text, 정책 버전, 사용자 범위, 모델에 대해서만 검사 결과를 재사용한다. 새로 생성된 텍스트·수정 요청을 이전 승인으로 무조건 통과시키지 않는다.
- 내부 프리비즈는 sceneDesign 및 실제 렌더 버전과 연결된 데이터만 재사용한다. 프로젝트만 같고 장면 버전이 다르면 재검증한다.
- 에셋 캐시는 이미지 바이트 해시와 역할에 연결한다. 에셋 교체 시 정체성·매핑·시작 이미지 캐시를 무효화하고 카메라·동선 캐시는 유지한다.
- 시작 이미지는 1회 생성을 기본 상한으로 한다. 시각적 경고만으로 다시 생성하지 않는다. 이미지 파일 자체가 없으면 성공으로 처리하거나 다른 이미지를 몰래 사용하지 않는다.
- 입력 검증이 최종 프롬프트를 통째로 다시 쓰지 않도록 한다. 스키마·길이·ID·시간·이미지 입력형식 등은 Python 검증이 맡고 시각 검증은 차이점만 반환한다.
- 별도 문장 미화·재번역·행동 재설계·길이 조절을 위한 AI 호출은 제거한다. 의미를 손실시키는 임의 문자열 자르기는 금지한다.
- 최종 영상의 경미한 취향 차이는 경고로 반환한다. 자동 재생성은 필수 품질 기준의 명확한 실패만 대상으로 하며 같은 job의 사용량에 합산한다.
- 전송 결과가 불명확한 이미지·영상 생성은 무조건 재제출하지 않는다. 공급사 작업 ID·멱등성을 확인한다.

| 항목 | 초기 목표 |
| --- | ---: |
| 사용자 요청·확정 장면 | 1,000자 |
| 공통 규칙 | 1,500자 |
| 카메라·배치·이벤트 타임라인 | 3,500자 |
| 캐릭터 행동·대사·음향 | 1,400자 |

## 검증과 성공 기준

동일한 모델·사용자 요청·길이·해상도·에셋으로 원본/최적화 결과를 비교한다. 단일 인물+사물, 다인 교차 동선, 큰 카메라 이동, 대사·음향, 외부 업로드 MP4를 포함한다.

1. 원본 파일 해시·실제 사용량·호출 목록·프롬프트 길이를 기준으로 보관한다.
2. 먼저 오프라인 계약·캐시·복원·예산·호출 수 테스트를 실행한다.
3. 원본과 최적화 경로를 요청 단위로 선택할 수 있게 단계별 적용한다. 의미 분석 전체를 한 번에 교체하지 않는다.
4. 실제 비교 생성은 공급사 연결·외부 전송 범위·비용을 확인한 뒤 수행한다. 이번 설계 단계에서는 실행하지 않는다.
5. 총 토큰 합계 비율 <= 1/3, 필수 행동·카메라·에셋 유지, 신체 분리·가림·급격한 장면 변경의 비증가를 함께 만족해야 한다.
6. 실패·수정·재생성까지 포함해 지표를 공개한다. 성공한 호출만 골라 비교하지 않는다.
