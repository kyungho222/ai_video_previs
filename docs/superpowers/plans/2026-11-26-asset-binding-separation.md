# 에셋 연결 저장 및 프레임 정보 분리

승인 범위: 최초 에셋–객체 연결을 영구 저장하고 자체 생성 프리비즈의 Blender 측정 정보를 재사용한다. 업로드 MP4의 기존 분석 경로는 유지한다. 이후 제안된 AI 프레임 분석의 완전 제거는 별도 작업이다.

1. `asset_object_bindings.py`: 원본 프리비즈와 객체 목록을 기준으로 연결 범위를 정하고, 에셋 순서와 독립적인 키로 SQLite에 의미적 연결만 저장한다. 프레임 좌표는 저장하지 않는다.
2. 같은 모듈에서 명시적 객체 연결과 저장된 연결을 읽고, 요청 프레임의 실제 측정값으로 매핑을 재구성한다. 측정되지 않은 가시성은 생성하지 않는다.
3. `spatial_guides.py`: 명시적/저장된 연결로 완성할 수 있으면 AI 호출을 생략한다. AI 결과에서도 연결과 프레임 측정을 분리하고 성공한 연결만 저장한다.
4. `video_preparation.py`: runtime/data의 연결 저장소를 전달한다. 외부 DB와 인증 저장소는 사용하지 않는다.
5. 연결 상태와 공간 분석 상태를 각각 기록한다. 다른 프리비즈·다른 에셋·변경된 객체에 저장된 연결을 재사용하지 않는다.
6. 테스트: 저장/재시작/에셋 순서 변경, 다른 장면 격리, 측정값 부재, 경고 데이터, 기존 MP4 호환, AI 호출 생략 검증.

검증 후 적용 상태와 남은 Blender 측정 데이터 한계를 명시한다. 실제 유료 생성과 운영 배포는 수행하지 않는다.

## 구현 및 검증

- 연결 전용 SQLite, 명시적 연결 우선, 에셋 순서와 독립적인 ID 키, 원본 프리비즈별 격리를 구현했다.
- 연결과 Blender 프레임 측정값이 모두 있으면 매핑 AI 호출을 생략한다. 일부만 있으면 측정 완료된 에셋은 유지하고 나머지만 분석한다.
- 공간 정보 출처를 `blender`와 `model`로 구분하고 연결 상태는 `assetBindingStatus`에 별도 기록한다.
- 관련 로컬 테스트 54개 통과. preparation 모듈 import 및 builder 연결 인자 검사 통과.
- 기존 Blender 내보내기에서 bbox/visibility가 없는 프레임은 측정 완료로 간주하지 않는다. 이 경우 기존 분석 경로를 유지한다. 전체 프레임의 실측 내보내기 확장과 AI 프레임 분석 완전 제거는 후속 범위다.
