# 인증 모듈화 구현 계획

요구: 인증 관련 기능은 `ai_video/jutsu_auth`에서 관리하고 메인 파이프라인은 호출만 한다.

## 구조

- `manager.py`: 설정, 클라이언트 생성, 연결 점검 직렬화, 주기 복구, 브라우저 승인, 제한 시간 내 준비 대기, 종료.
- `routes.py`: 기존 status/connect/connect-browser/callback API. 주소·응답·오류 형식 유지.
- 기존 `jutsu_auth.py`, `browser_approval.py`: OAuth/MCP 및 브라우저 조작 담당 유지.
- `app.py`: 관리자 생성, 라우터 등록, 수명주기 호출만 담당.
- `agent.py`, 영상/카메라 참조 준비: 공통 인증 준비 함수를 호출. 실제 도구 실행은 재전송하지 않는다.
- OAuth SQLite와 브라우저 프로필의 기존 경로 유지. 자격증명이나 OAuth URL은 로그에 출력하지 않는다.

## 작업

1. 관리자·API·대기/종료 회귀 테스트 작성 후 실패 확인.
2. 인증 관리와 API를 분리하고 호출부 교체.
3. 기존 브라우저 승인, 시나리오/프리비즈, 영상 참조 및 라우팅 회귀 테스트 실행.
4. 진행 중 작업 확인 후 로컬 서버 반영. 서버 응답과 인증 상태는 구분하여 보고.

연결 준비는 connected 상태까지 제한 시간 동안 대기한다. 인증 대기 자체를 인증 완료로 간주하지 않는다.
Google 계정 선택/추가 인증 자동화는 이번 구조 변경의 범위에 추가하지 않는다.
