# whoami 전환과 무중단 모델 설정 적용

기존 `whoami`를 사용하는 서비스를 `refactor/whoami`의 중앙 모델 DB·runtime 갱신 구조로 전환하기 위한 전달 묶음입니다. 사용자별 OpenAI API 키 분기도 포함합니다.

여기서 무중단은 **전환 완료 후 지원하는 모델 설정을 프로세스 재시작 없이 새 요청에 반영하는 동작**입니다. 최초 코드·SDK·환경 교체에는 배포와 프로세스 재시작이 필요합니다. 최초 배포 중 서비스 연결을 유지하는 방법은 대상 서비스의 배포 구성에 따릅니다.

## 포함 파일

| 파일 | 적용 방법 |
| --- | --- |
| [utils/whoami.py](utils/whoami.py) | 현재 공통 설정 로더와 SDK 생성 함수. 기존 import 위치와 서비스 전용 함수를 비교해 적용 |
| [utils/whoami_db.py](utils/whoami_db.py) | Chatty의 DB·업로드 도우미 참고본. 사용하는 서비스만 의존성과 함수 계약을 비교해 적용 |

복사본은 2026-10-29 `refactor/whoami`의 `d66bf9e3` 기준이며, API 계정 분기 추가 커밋은 `6e2fe52d`입니다. 실행 서버 배포 완료를 뜻하지 않습니다. `WHOAMI_VERSION` 문자열만으로 파일 일치 여부를 판단하지 않습니다.

실제 API 키·DB 비밀번호·서비스 `config.py`·운영 `runtime.json`은 포함하지 않았습니다. 중앙 모델 DB의 schema와 초기 등록은 관리 서버 담당자가 준비하고, 소비 서비스는 그 설정을 읽습니다.

두 파일 교체만으로 영상·이미지 실행기, 관리자 API·화면, 채팅 저장 기능까지 이관되지는 않습니다. 대상 기능의 호출부도 새 설정을 읽는지 확인합니다.
